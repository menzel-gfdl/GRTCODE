13  !!@section Overview
14  !! Given an atmospheric column made up of at least one layer,
15  !! this code calculates the total optical depth of each layer
16  !! at each point on an input spectral grid. Unlike the
17  !! @ref lowlevelfortranapi, this API provides simplified interfaces,
18  !! at the cost of thread-safety and more fine-grained control with the
19  !! goal of making this library more accessible to users
20  !! familiar with Fortran paradigms currently used in GCMs.
21  !! To use this API,
22  !!
23  !! use molecular_lines_fhl
24  !!
25  !! and follow these steps:
26  !! -# Initialize the library by calling the
27  !! @ref grt_context_init_fhl function. Here you must provide
28  !! an array of paths HITRAN database files, where each path
29  !! in the array corresponds to a molecule that will be used
30  !! in the optical depth calculation.
31  !! @attention You must call this function before calling any
32  !! other function included in this library. Failure to do
33  !! so will result in undefined behavior.
34  !!
35  !! In addition, the following optional parameters may be set (not
36  !! passing these arguments in implies using the default values):
37  !! - A path to a file containg a Fortran namelist. As described
38  !! below, the number of levels per atmospheric column and
39  !! parameters (lower bound, upper bound, and resolution) for
40  !! the spectral grid on which the optical depths will be
41  !! calculated are namelist controlled. If this argument is
42  !! not passed in, the default values described in the section
43  !! below will be used.
44  !! - A cutoff value for the molecular lines. This
45  !! value denotes how far (in terms of wavenumber) from the line
46  !! center each molecular line is calculated out to. By default
47  !! this value is set to 25 [1/cm], so if for example a line
48  !! center lies at the wavenumber 150 [1/cm], then it contributes
49  !! to the optical depth at all spectral grid points in the range
50  !! 125 <= w <= 175 [1/cm].
51  !! - The id of the GPU device you'd like the library to use
52  !! (see the readme for a simple way to determine the ids of
53  !! any GPUs you may have on your system). If you do not specify a
54  !! GPU id when initializing the library,
55  !! the library will query the system for available
56  !! GPUs. If any are found, then the first device (device 0) will be used.
57  !! If you wish to force the code to run on your host CPU, pass in a value
58  !! of -1.
59  !! - If you wish to run with either the water vapor
60  !! or ozone continua, you must provide a path to a directory
61  !! containing the necessary input files. The required input
62  !! files are included with this library in directories named
63  !! "water_vapor_continuum" and "ozone_continuum" respectively,
64  !! and are located in the base directory of this repository.
65  !! -# Calculate the optical depth for each layer in the column at each
66  !! spectral grid point by calling the @ref grt_calculate_optical_depth_fhl
67  !! function.
68  !! @attention All input arrays must be contiguous. In addition,
69  !! the number of elements in the input pressure [atm] and
70  !! temperature [K] arrays must be equal to the number of
71  !! atmospheric levels. The input abundance array [ppmv]
72  !! must be two-dimensional, and layed out in memory as
73  !! (level,molecule), where the molecules must be in the
74  !! same order as they were in the array of HITRAN file paths
75  !! that was passed into the @ref grt_context_init_fhl
76  !! routine. The input optical depth array must also be
77  !! two-dimensional, and layed out in memory as (wavenumber,
78  !! layers), where the number of atmospheric layers must
79  !! equal the number of atmospheric levels minus one and the
80  !! size of the wavenumber dimension must equal the number
81  !! of spectral grid points (returned by the
82  !! @ref grt_get_spectral_grid_size_fhl function). If any of
83  !! these arrays are not contiguous or have an incorrect size,
84  !! the behavior is undefined.
85  !!
86  !! -# Release the memory allocated by the libray by calling the
87  !! @ref grt_context_free_f function.
88  !! \section Namelist
89  !! Runtime arguments can be supplied via a Fortran namelist titled
90  !! <c>molecular_lines_nml</c>. A path to the file containing
91  !! the namelist may be passed as an optional argument to the
92  !! @ref grt_context_init_fhl routine. An example namelist is
93  !! included in a directory named namelist in the base directory of
94  !! this repository. If no path is provided, default
95  !! values are used.
96  !! \param num_levels <b> Integer(kind=c_int) </b> number of
97  !! atmospheric levels. Defaults to 60.
98  !! \param w0 <b> Real(kind=c_double) </b> lower bound [1/cm] of
99  !! spectral grid. Defaults to 1.
100  !! \param wn <b> Real(kind=c_double) </b> upper bound [1/cm] of
101  !! spectral grid. Defaults to 3250.
102  !! \param wres <b> Real(kind=c_double) </b> resolution [1/cm] of
103  !! spectral grid. Defaults to 0.1.
104  !! @note Each atmospheric level corresponds to an interface
105  !! between adjacent atmospheric layers or the lower/upper
106  !! edge of the atmosphere. Thus, the number of atmospheric
107  !! levels = the number of atmospheric layers plus one.
108  !! Since at least one atmospheric layer is required,
109  !! the number of atmospheric levels must be greater than or
110  !!
111  !!@section Limitations
112  !! This API aims to simply the function interfaces by managing
113  !! the library context internally. Because of this, only a single
114  !! library context is used, and thus:
115  !! - The library is no longer thread-safe. Calling these functions
116  !! in OpenMP threaded regions will lead to undefined behavior.
117  !! - The library is restricted to only using a single GPU.
118  !!
119  !! If greater control over parallelism is required, please use the
120  !! @ref lowlevelfortranapi.
121  !!@section Example
122  !!Here is a simple example demonstrating how to use this library.
123  !!@include example_fhl.F90
124  !!In order to build this code, copy this code into a file, modify
125  !!the paths to input files (as needed), and (assuming you have gcc
126  !!installed) run:
127  !!
128  !! $ gfortran <file> -fopenmp -o example.x -I<path to library include directory> \
129  !! -L<path to library lib directory> -lmolecular_lines \
130  !! -Wl,-rpath=<path to library lib directory>
131  !!
132  !!To run this example on your GPU, make sure that you have compiled
133  !!the library using the NVCC compiler (i.e., by using the provided
134  !!Makefile.nvcc).

369  !! @brief Calculate the total optical depth of each atmospheric
370  !! layer at each spectral grid point.
371  subroutine grt_calculate_optical_depth_fhl(pressure, &
372  temperature, &
373  ppmv, &
374  optical_depth)
375 
376  !Inputs/outputs
377  real(kind=fp),dimension(:),intent(in) :: pressure !< Array of atmospheric pressures [atm].
378  !! The size of this array must be
379  !! equal to the number of atmospheric
380  !! levels.
381  real(kind=fp),dimension(:),intent(in) :: temperature !< Array of atmospheric temperatures [K].
382  !! The size of this array must be
383  !! equal to the number of atmospheric
384  !! levels.
385  real(kind=fp),dimension(:,:),intent(in) :: ppmv !< Array of molecular abundances [ppmv].
386  !! This array must be of size (num_layers,molecules).
387  real(kind=fp),dimension(:,:),intent(inout) :: optical_depth !< Array of atmospheric optical depths.
388  !! The size of this array must be equal
389  !! to the number of atmospheric layers
390  !! times the number of spectral grid
391  !! points. Memory is layed out as
392  !! (wavenumber,layer) (i.e., the
393  !! fastest changing dimension is the
394  !! one corresponding to the spectral
395  !! grid.)
396  !Local variables
397  integer(kind=c_int) :: return_code
398  integer(kind=c_int) :: i
399  integer(kind=c_int) :: num_mols
400 
401  call omp_thread_trap()
402  return_code = grt_get_num_molecules_f(context, &
403  num_mols)
404  call check_rc(return_code)
405 
406  if (size(ppmv,1) .ne. num_levels .or. size(ppmv,2) .ne. &
407  num_mols) then
408  call error("input ppmv array must be of size" &
409  //"(num_levels,num_molecules).")
410  stop 1
411  endif
412  do i = 1,num_mols
413  return_code = grt_set_molecule_ppmv_f(context, &
414  i-1, &
415  ppmv(:,i))
416  call check_rc(return_code)
417  enddo
418  if (size(pressure) .ne. num_levels .or. size(temperature) .ne. &
419  num_levels) then
420  call error("input pressure and temperature must" &
421  //" be of size num_levels.")
422  stop 1
423  endif
424  return_code = grt_calculate_optical_depth_f(context, &
425  pressure, &
426  temperature, &
427  optical_depth)
428  call check_rc(return_code)
429  end subroutine grt_calculate_optical_depth_fhl
