9 /**
10  @defgroup capi C API
11  @section Overview
12  Given an atmospheric column made up of at least one layer,
13  this code calculates the total optical depth of each layer
14  at each point on an input spectral grid. To use this API,
15 
16  #include "molecular_lines.h"
17 
18  and follow these steps:
19  -# Declare library context pointer(s). These variables must be
20  pointers of type GrtContext_t, as in:
21 
22  GrtContext_t *x;
23 
24  Each context pointer will
25  hold the address of a struct that contains data that is
26  required by the library.
27  @note Each context can be associated with a single GPU. If
28  you wish to use multiple GPUs, you must create a context
29  pointer for each GPU you wish to use and pass
30  in the appropriate device id when initializing the context
31  pointer (i.e., by calling the @ref grt_context_init
32  function).
33 
34  -# Initialize the context pointer(s) by calling the
35  @ref grt_context_init function. Here you must provide the
36  number of levels per atmospheric column and parameters
37  (lower bound, upper bound, and resolution) for the
38  spectral grid on which the optical depths will be calculated.
39  @attention You must call this function before calling any
40  other function included in this library. Failure to do
41  so will result in undefined behavior.
42  @note Each atmospheric level corresponds to an interface
43  between adjacent atmospheric layers or the lower/upper
44  edge of the atmosphere. Thus, the number of atmospheric
45  levels = the number of atmospheric layers plus one.
46  Since at least one atmospheric layer is required,
47  the number of atmospheric levels must be greater than or
48  equal to two.
49 
50  In addition, the following parameters may be set (passing
51  in NULL implies using the default values):
52  - A cutoff value for the molecular lines. This
53  value denotes how far (in terms of wavenumber) from the line
54  center each molecular line is calculated out to. By default
55  this value is set to 25 [1/cm], so if for example a line
56  center lies at the wavenumber 150 [1/cm], then it contributes
57  to the optical depth at all spectral grid points in the range
58  125 <= w <= 175 [1/cm].
59  - The id of the GPU device you wish to associate with this
60  context (see the readme for a simple way to determine the ids of
61  any GPUs you may have on your system). If you do not specify a
62  GPU id when initializing the context (i.e., by passing in NULL
63  for this argument), the library will query the system for available
64  GPUs. If any are found, then the first device (device 0) will be used.
65  If you wish to force the code to run on your host CPU, pass in a value
66  of -1.
67  - If you wish to run with either the water vapor
68  or ozone continua, you must provide a path to a directory
69  containing the necessary input files. The required input
70  files are included with this library in directories named
71  "water_vapor_continuum" and "ozone_continuum" respectively,
72  and are located in the base directory of this repository.
73  If you wish to run without either continuum, instead pass
74  in the value NULL.
75  -# Add each molecule that you want included in the optical
76  depth calculation by calling the @ref grt_add_molecule function.
77  Each added molecule requires an ascii [HITRAN](http://hitran.org)
78  database file containing the necessary molecular line parameters. The
79  format of these files must match that described in Table 1 of
80  [Rothman et al. 2013, Journal of Quantitative Spectroscopy & Radiative
81  Transfer, 130](http://dx.doi.org/10.1016/j.jqsrt.2013.07.002).
82  Example HITRAN database files for a select set of molecules are included
83  with this library in a directory labeled HITRAN_files in the base of this
84  repository.
85  @attention Ozone and water vapor continua will only be
86  included in the optical depth calculation if the ozone
87  and water vapor molecules are added.
88 
89  -# Set the abundance [ppmv] of each added molecule by calling
90  the @ref grt_set_molecule_ppmv function.
91  @attention The input abundance array must be contiguous and
92  its size (number of elements) must be equal to the number
93  of atmospheric levels passed into the @ref grt_context_init
94  function, or else the behavior is undefined.
95 
96  -# Calculate the optical depth for each layer in the column at each
97  spectral grid point by calling the @ref grt_calculate_optical_depth
98  function.
99  @attention All input arrays must be contiguous. In addition,
100  the number of elements in the input pressure [atm] and
101  temperature [K] arrays must be equal to the number of
102  atmospheric levels. The number of elements in the input
103  optical depth array must be equal to the number of
104  atmospheric layers (number of atmospheric levels minus one)
105  times the number of spectral grid points (returned by
106  the @ref grt_get_spectral_grid_size function). If any of
107  these arrays are not contiguous or have an incorrect size,
108  the behavior is undefined.
109 
110  -# Release the memory allocated by the context(s) by calling the
111  @ref grt_context_free function.
112  @section Example
113  Here is a simple example demonstrating how to use this library.
114  @include example.c
115  In order to build this code, copy this code into a file, modify
116  the paths to input files (as needed), and (assuming you have gcc
117  installed) run:
118 
119  $ gcc <file> -fopenmp -o example.x -I<path to library include directory> \
120  -L<path to library lib directory> -lmolecular_lines \
121  -Wl,-rpath=<path to library lib directory>
122 
123  To run this example on your GPU, make sure that you have compiled
124  the library using the NVCC compiler (i.e., by using the provided
125  Makefile.nvcc).
126 */
